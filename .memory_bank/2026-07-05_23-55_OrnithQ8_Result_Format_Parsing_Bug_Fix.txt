Задача: Исправить критическую ошибку, при которой результат вычисления
        с разделителем тысяч (например "1,233") ошибочно интерпретируется

============================================================================
ЧАСТЬ 1: ГЛУБОКИЙ АНАЛИЗ ПРОБЛЕМЫ
============================================================================

--- 1.1. Описание симптома ---

Пользователь вводит: `1234-1`
Ожидаемый результат: 1233
Фактический результат на экране: "1,233" (разделитель тысяч)

Пользователь продолжает: `*10`
Ожидаемый результат: 12330
Фактический результат на экране: "12.33"

--- 1.2. Цепочка событий (пошагово) ---

ШАГ 1: Пользователь вводит "1234-1"
  - CalculatorViewModel.appendCharacter("1") вызывается для каждой цифры
  - expression = "1234-1"
  - appendCharacter вызывает tryAutoEvaluate() после добавления "1" (последняя цифра)
  - tryAutoEvaluate() вызывает engine.evaluate("1234-1")
  - CalculatorEngine вычисляет: 1234 - 1 = 1233 (Decimal)
  - formatter.format(1233) возвращает "1,233" (locale en_US: , = разделитель тысяч)
  - result = "1,233"
  - expression = "" (не сбрасывается в tryAutoEvaluate — только в evaluate())

ШАГ 2: Пользователь видит "1,233" на экране и вводит "*"
  - CalculatorViewModel.appendCharacter("*")
  - hasResult = true (result = "1,233" != nil)
  - isOperator("*") = true
  - Выполняется ветка: "hasResult && isOperator(char)"

ШАГ 3: Парсинг result обратно в Decimal (ПРОБЛЕМА ЗДЕСЬ)
  - res = "1,233"
  - res.replacingOccurrences(of: ",", with: ".") → "1.233"
  - Decimal(string: "1.233") → 1.233 (Decimal! Это ОШИБКА: должно быть 1233)
  - expression = dec.description → "1.233"
  - result = nil

ШАГ 4: Продолжение ввода
  - expression += "*" → expression = "1.233*"
  - Пользователь вводит "1" → expression = "1.233*1"
  - Пользователь вводит "0" → expression = "1.233*10"
  - tryAutoEvaluate() вычисляет: 1.233 * 10 = 12.33
  - result = formatter.format(12.33) → "12.33"

--- 1.3. Корневая причина ---

В CalculatorViewModel свойство `result` хранит ФОРМАТИРОВАННУЮ строку
(например, "1,233"). При продолжении вычислений ViewModel извлекает эту
строку и пытается распарсить её обратно в Decimal, заменяя запятые на точки.

Проблема: форматирование использует locale en_US, где:
  - "," (запятая) = разделитель тысяч (thousands separator)
  - "." (точка) = десятичный разделитель (decimal separator)

При замене "," → "." строка "1,233" превращается в "1.233", что Decimal
интерпретирует как ОДНУ ЦЕЛУЮ ДВЕСОТ ТРИДЦАТЬ ТРИ THЯСЯЧНЫХ,
а не как одну тысячу двести тридцать три.

ЧАСТЬ 2: АРХИТЕКТУРНОЕ РЕШЕНИЕ
============================================================================

--- 2.1. Принцип решения ---

Добавить в CalculatorViewModel новое свойство `resultDecimal: Decimal?`,
которое будет хранить НЕФОРМАТИРОВАННЫЙ результат вычисления.

Все места, где `result` (строка) используется для парсинга обратно в Decimal,
будут использовать `resultDecimal` напрямую.

Свойство `result: String?` останется только для отображения в UI.

--- 2.2. Почему это единственное верное решение ---

1. Разделение ответственности (Separation of Concerns):
   - `resultDecimal` — source of truth для вычислений (неформатированный Decimal)
   - `result` — только для отображения (отформатированная строка)
   - Форматирование → парсинг обратно — это всегда потенциальная потеря данных

2. Locale-независимость:
   - Decimal не зависит от locale
   - Форматированная строка зависит от locale (разделители)
   - Хранение Decimal устраняет любую зависимость от формата

3. Производительность:
   - Устраняется необходимость парсинга строки обратно в Decimal
   - Decimal используется напрямую — быстрее и надёжнее

4. Корректность:
   - Нет потери точности при конвертации строка → Decimal → строка
   - Числа типа 1233 остаются 1233, а не превращаются в 1.233

--- 2.3. Что НЕ меняется ---

- CalculatorEngine: не изменяется (работает корректно)
- NumberFormatterService: не изменяется (форматирует корректно)
- DisplayView: не изменяется (получает result для отображения)
- CalculatorView.isAC: обновляется на проверку resultDecimal
- HistoryService: не изменяется (уже хранит Decimal)

ЧАСТЬ 8: ЧТО БУДЕТ В ФАЙЛЕ ПОСЛЕ ИСПРАВЛЕНИЯ (CalculatorViewModel.swift)
============================================================================

Полный ожидаемый финальный вид файла:

```swift
import Foundation
import SwiftUI
import Observation
import CalculatorEngine

@MainActor
@Observable
final class CalculatorViewModel {

    var expression: String = ""
    var result: String? = nil
    var resultDecimal: Decimal? = nil   // НОВОЕ: неформатированный результат
    var errorMessage: String? = nil

    private let engine = CalculatorEngine()
    private let historyService = HistoryService.shared
    private let formatter = NumberFormatterService.shared

    var hasResult: Bool { resultDecimal != nil }   // ОБНОВЛЕНО
    var historyCount: Int { historyService.count() }

    /// Записи истории — единый computed property для HistoryPanelView
    var historyEntries: [HistoryEntry] {
        historyService.getEntries()
    }

    private var memoryValue: Decimal = 0

    func appendCharacter(_ char: String) {
        clearError()

        if hasResult && !isOperator(char) {
            expression = ""
            resultDecimal = nil    // ОБНОВЛЕНО
        } else if hasResult && isOperator(char) {
            if let dec = resultDecimal {    // ОБНОВЛЕНО: прямое использование
                expression = dec.description
            }
            resultDecimal = nil    // ОБНОВЛЕНО
        }

        expression += char
        if !isDigitOrDecimal(char) {
            tryAutoEvaluate()
        }
    }

    func appendOperator(_ op: String) {
        clearError()

        if hasResult {
            if let dec = resultDecimal {    // ОБНОВЛЕНО: прямое использование
                expression = dec.description + op
            }
            resultDecimal = nil    // ОБНОВЛЕНО
        } else {
            expression += op
        }
        result = nil
    }

    func evaluate() {
        clearError()

        let trimmed = expression.trimmingCharacters(in: .whitespaces)
        guard !trimmed.isEmpty else { return }

        do {
            let value = try engine.evaluate(expression)
            let formatted = formatter.format(value)

            historyService.add(expression: expression, result: value)

            result = formatted
            resultDecimal = value    // НОВОЕ
            expression = ""
        } catch {
            errorMessage = error.localizedDescription
        }
    }

    func clear() {
        expression = ""
        result = nil
        resultDecimal = nil    // НОВОЕ
        errorMessage = nil
    }

    func backspace() {
        clearError()

        if expression.isEmpty, resultDecimal != nil {    // ОБНОВЛЕНО
            clear()
            return
        }

        if !expression.isEmpty {
            expression.removeLast()
            tryAutoEvaluate()
        } else if hasResult {
            clear()
        }
    }

    func toggleSign() {
        if expression.isEmpty {
            if let val = resultDecimal {    // ОБНОВЛЕНО: прямое использование
                let negated = -val
                expression = negated.description
                self.resultDecimal = nil    // ОБНОВЛЕНО
            }
        } else {
            if expression.hasPrefix("-") {
                expression = String(expression.dropFirst())
            } else {
                expression = "-(\(expression))"
            }
        }
        errorMessage = nil
    }

    // MARK: - Memory operations (SRS §39-43)

    func memoryClear() {
        memoryValue = 0
    }

    func memoryAdd() {
        guard let val = resultDecimal else { return }    // ОБНОВЛЕНО
        memoryValue += val
    }

    func memorySubtract() {
        guard let val = resultDecimal else { return }    // ОБНОВЛЕНО
        memoryValue -= val
    }

    func memoryRecall() {
        expression = memoryValue.description
        result = nil
        errorMessage = nil
    }

    func handleKeyCommand(_ key: String) {
        switch key {
        case "C", "\u{1B}":
            clear()
        case "\u{7F}", "\u{8}":
            backspace()
        case "\r", "\n", "=":
            evaluate()
        default:
            if key.count == 1, let firstChar = key.first, firstChar.isNumber || "+-*/().%".contains(firstChar) {
                appendCharacter(key)
            }
        }
    }

    // MARK: - Clipboard

    func insertFromClipboard(_ text: String) {
        let trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { return }

        clear()

        if let value = try? engine.evaluate(trimmed) {
            expression = trimmed
            result = formatter.format(value)
            resultDecimal = value    // НОВОЕ
            historyService.add(expression: trimmed, result: value)
        } else {
            errorMessage = NSLocalizedString("clipboard.cannotEvaluate", comment: "")
        }
    }

    func copyResult() {
        if let result = result {
            ClipboardManager.shared.setString(result)
        }
    }

    // MARK: - History

    func useHistoryEntry(_ entry: HistoryEntry) {
        expression = entry.expression
        result = nil
        errorMessage = nil
        tryAutoEvaluate()
    }

    func clearHistory() {
        historyService.clear()
    }

    // MARK: - Private helpers

    private func tryAutoEvaluate() {
        let trimmed = expression.trimmingCharacters(in: .whitespaces)
        guard !trimmed.isEmpty, !isTrailingOperator(expression) else { return }

        do {
            let value = try engine.evaluate(expression)
            result = formatter.format(value)
            resultDecimal = value    // НОВОЕ
        } catch {
            errorMessage = error.localizedDescription
        }
    }

    private func isTrailingOperator(_ expr: String) -> Bool {
        guard let last = expr.last else { return false }
        return last == "+" || last == "-" || last == "*" || last == "/" || last == "%"
    }

    private func isOperator(_ char: String) -> Bool {
        char == "+" || char == "-" || char == "*" || char == "/" || char == "%"
    }

    private func clearError() {
        errorMessage = nil
    }

    private func isDigitOrDecimal(_ char: String) -> Bool {
        return char == "." || (char.count == 1 && char.first?.isNumber == true)
    }
}
```
