## 3. Уникальные находки каждого агента

### 3.1 UnslothMTP — уникальные находки

**Критическая находка: Потенциальные бесконечные циклы в Tokenizer**

UnslothMTP единственный провёл детальный анализ граничных случаев токенизации и обнаружил **пять случаев потенциального бесконечного цикла**:

1. **«.» (одиночная точка)** — `readNumber` возвращает `(0, startIndex)` без продвижения индекса
2. **«1..5» (две точки)** — аналогично, бесконечный цикл
3. **«0x» (hex без цифр)** — `readHex` возвращает `(0, start)`
4. **«0b» (binary без цифр)** — аналогично
5. **«0o» (octal без цифр)** — аналогично

Также обнаружена **неиспользуемая ошибка** `multipleDecimalSeparators` в CalculatorError — код для обработки ошибки есть, но он нигде не вызывается.

**Другие уникальные находки:**
- M-09: `@unchecked Sendable` обходит проверки Swift Concurrency — рекомендовано использовать `actor`
- M-07: Унарный минус имеет более высокий приоритет чем percent — семантически неверно
- N-03: `AnyShape` имеет расширение `@unchecked Sendable`
- N-09: `formatter.format(dec)` в ViewModel записывает локализованную строку обратно в expression — потенциальная ошибка парсинга при последующем evaluate()
- Детальная матрица соответствия SRS (секции 1-96)

### 3.2 Sonnet — уникальные находки

Sonnet обнаружил **наибольшее количество критических проблем**, многие из которых не были найдены другими агентами:

**Критическая находка: Тесты не интегрированы в Package.swift (#A-03)**

> Package.swift не содержит `.testTarget()`. При запуске `swift test` не выполнится ни один тест.

Это грубое нарушение SRS §90 и §93 (Definition of Done: «Все тесты успешно проходят»). **Ни UnslothMTP, ни OrnithQ8 эту проблему не обнаружили.**

**Критическая находка: Ошибка типа при распознавании «pi» (#E-01)**

```swift
if char.lowercased() == "pi"  // char — один символ, не может равняться "pi"
```

`Character.lowercased()` возвращает `String`, но строка одного символа (`"p"`) никогда не равна `"pi"`. Тест `testTokenize_PiKeyword` должен падать, но ожидает успех. **Это фундаментальная ошибка, не обнаруженная другими агентами.**

**Критическая находка: Неверная ошибка при незакрытой скобке (#E-03)**

В `Parser.swift` при незакрытой скобке `(15+16` выбрасывается `extraClosingParenthesis` вместо `missingClosingParenthesis`. SRS §33 требует различать эти случаи. **Никто другой не обнаружил.**

**Критическая находка: Вставка из буфера не отображает выражение (#V-01)**

```swift
if let value = try? engine.evaluate(trimmed) {
    expression = ""  // ВЫРАЖЕНИЕ ОЧИЩАЕТСЯ!
    result = formatter.format(value)
```

При вставке через ⌘V пользователь видит только результат, но не само выражение. SRS §38 и §52 требуют: «Шаг 2: Выражение появляется на дисплее. Шаг 3: Автоматически вычисляется.»

**Критическая находка: Package.swift пропускает директории (#A-02)**

```swift
sources: ["App", "Views", "ViewModels", "Services",
          "History", "Clipboard", "Models", "Formatting", "Theme"]
```

Пропущены: `Components/`, `Extensions/`, `Localization/`. EmptyStateView, Decimal+Extensions, String+Calculator и файлы локализации **фактически не компилируются**.

**Другие существенные находки:**
- #V-04: `toggleSign` не работает с форматированными числами (тысячные разделители)
- #V-05: `memoryAdd/memorySubtract` аналогичная проблема
- #UI-03: `.replacingOccurrences(of: ".", with: ",")` заменяет точки безусловно — в английской локали `3.14` станет `3,14`
- #UI-04: Унарный и бинарный минус не различаются при форматировании `-(15+16)` → ` − (15 − 16)`
- #S-02: Неверная логика форматирования экспоненциальных чисел (замена "e+" когда NumberFormatter выдаёт "E+")
- #ST-01: История не сохраняется между сессиями (только в памяти)
- #T-03: Ожидание 1000 для "e3" логически невозможно
- #T-04: Сравнение через `.description` ненадёжно для Decimal

### 3.3 OrnithQ8 — уникальные находки

**Критическая находка: TODO в production-коде**

```swift
case .secondFunc:
    break // TODO: переключение режима кнопок (2ⁿᵈ)
```

SRS Section 93 требует: «Нет TODO. Нет временных решений. Нет заглушек.» **Ни UnslothMTP, ни Sonnet эту проблему не обнаружили.**

**Уникальные замечания:**
- Dynamic Type не поддерживается (фиксированные размеры шрифтов)
- Reduce Motion частично не реализован (анимации работают независимо от системной настройки)
- Проблема с обработкой константы "e" при "e3" (сочтено проблемой, хотя SRS это допускает)

## 7. Вердикт

**Sonnet** выдал наиболее полный и технически точный аудит. Он единственный обнаружил 5 критических проблем, пропущенных остальными:
- Тесты не интегрированы в Package.swift
- Ошибка типа при распознавании «pi»
- Неверная ошибка скобок
- Вставка из буфера скрывает выражение
- Package.swift пропускает директории

**UnslothMTP** лучше всех проанализировал граничные случаи и структурировал результаты. Его находки по бесконечным циклам в Tokenizer критически важны.

**OrnithQ8** предоставил наиболее читабельный отчёт, но пропустил больше всего критических проблем.

**Рекомендация:** Приоритет исправлений определять по объединённому списку P0-P3 выше. Каждую проблему верифицировать по исходному коду перед исправлением, так как три агента могли ошибиться в деталях.
