# План: Исправление кнопки «0» и выравнивание нижнего ряда

**Дата:** 2026-07-06  
**Автор:** OrnithQ8  
**Задача:** Сделать кнопку «0» обычной (как все остальные кнопки с цифрами), выровнять нижний ряд кнопок по сетке 4×7.

---

## 1. Анализ проблемы

### 1.1. Текущее состояние кнопки «0»

Кнопка «0» определена в `Sources/Views/CalculatorView.swift:104`:

```swift
ButtonSpec(label: .digit("0"), type: .digit, isWide: true),
```

Свойство `isWide: true` активирует три визуальных эффекта в компоненте `CalculatorButton`:

| Эффект | Файл | Строка | Описание |
|---|---|---|---|
| Удвоенная ширина | `CalculatorButton.swift` | 181 | `let targetWidth = spec.isWide ? diameter * 2 + spacing : diameter` — ширина кнопки «0» = 60×2+8 = 128pt вместо 60pt |
| Форма Capsule | `CalculatorButton.swift` | 198–201 | `.clipShape(spec.isWide ? AnyShape(Capsule()) : AnyShape(RoundedRectangle(cornerRadius: buttonCornerRadius)))` — скруглённая капсула вместо прямоугольника со скруглёнными углами |
| Отсутствие обводки | `CalculatorButton.swift` | 204 | `if hasBorder && !spec.isWide { ... }` — обводка применяется только если кнопка НЕ широкая |

### 1.2. Почему нижний ряд не выровнен

Сетка калькулятора — это 4 колонки × 7 строк, где каждая кнопка имеет ширину `buttonDiameter = 60pt` и расстояние между кнопками `buttonSpacing = 8pt`.

**Другие строки (4 кнопки):**
```
60 + 8 + 60 + 8 + 60 + 8 + 60 = 236pt
```

**Нижняя строка (с широкой кнопкой «0»):**
```
60 + 8 + 60 + 8 + (128) + 8 + 60 = 332pt
```

Кнопка «0» занимает ширину двух кнопок + промежуток, что смещает кнопку запятой вправо и нарушает выравнивание всей строки.

### 1.3. Архитектурное обоснование решения

Единственное архитектурно верное решение — **убрать `isWide: true`** из определения кнопки «0» в `CalculatorView.swift`.

Обоснование:
- Свойство `isWide` в `ButtonSpec` (`Sources/Views/CalculatorButton.swift:109`) — это **единственный механизм** управления шириной кнопки.
- Изменение `isWide` с `true` на `false` (или удаление флага) автоматически устраняет все три визуальных эффекта: удвоенную ширину, форму Capsule и отсутствие обводки.
- Это **единственное** место в коде, где кнопка «0» получает `isWide: true` — других вызовов нет.
- Изменение затрагивает **только один файл** (`CalculatorView.swift`), не требуя модификации `CalculatorButton.swift`, `ButtonSpec` или других компонентов.
- Метод `handleButtonPress` (`CalculatorView.swift:131`) обрабатывает `.digit(let d)` без учёта `isWide` — поведение нажатия не изменится.

## 3. План реализации (пошаговый)

### Шаг 1: Изменить определение кнопки «0» в CalculatorView.swift

**Файл:** `Sources/Views/CalculatorView.swift`  
**Строка:** 104

**Было:**
```swift
ButtonSpec(label: .digit("0"), type: .digit, isWide: true),
```

**Стало:**
```swift
ButtonSpec(label: .digit("0"), type: .digit),
```

**Обоснование:** Удаление `isWide: true` означает, что Swift использует значение по умолчанию `false`, определённое в `ButtonSpec.isWide: Bool = false` (`Sources/Views/CalculatorButton.swift:109`). Это делает кнопку «0» обычной — одинаковой ширины с другими кнопками.

**Эффекты этого изменения (все происходят автоматически, без дополнительных правок):**

1. `targetWidth` в `CalculatorButton.swift:181` вычислится как `diameter = 60pt` (вместо `128pt`).
2. `.clipShape(...)` в `CalculatorButton.swift:198–201` применит `RoundedRectangle(cornerRadius: 12)` (вместо `Capsule()`).
3. `.overlay { ... }` в `CalculatorButton.swift:204` применит обводку (`RoundedRectangle(cornerRadius: 12).stroke(borderColor, lineWidth: 1.0)`), так как `hasBorder == true` и `!spec.isWide == true`.
4. `.frame(width: targetWidth, height: diameter)` в `CalculatorButton.swift:192` и `.frame(width: targetWidth, height: diameter)` в `CalculatorButton.swift:220` установят размер 60×60pt.

### Шаг 2: Проверка отсутствия побочных эффектов

После изменения проверить, что:
- `handleButtonPress` (`CalculatorView.swift:131`) — не затронут, обработка `.digit(let d)` unchanged.
- `buttonRow` (`CalculatorView.swift:113`) — не затронут, `ForEach` итерация unchanged.
- `CalculatorButton.swift` — не требует изменений, вся логика `isWide` корректно обрабатывает `false`.
- `ButtonSpec.swift` — не требует изменений, свойство `isWide` остаётся с дефолтом `false`.
