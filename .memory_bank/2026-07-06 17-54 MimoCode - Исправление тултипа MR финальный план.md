# План исправления: тултип MR показывает "memory.tooltip10" вместо хранимого значения

**Дата:** 2026-07-06
**Автор:** MimoCode
**Статус:** План готов к утверждению
**Проблема:** При наведении курсора на кнопку MR подсказка показывает `memory.tooltip10` (где 10 — значение памяти) вместо чистого значения. Подсказка также появляется с задержкой ~5 секунд.

---

## 1. Диагностика: цепочка данных от нажатия M+ до отображения тултипа

| Этап | Файл:строка | Что происходит |
|---|---|---|
| `memoryAdd()` вызван | `CalculatorViewModel.swift:156-158` | `memoryValue += val` (Decimal) |
| `hasMemory` вычисляется | `CalculatorViewModel.swift:42` | `memoryValue != 0` → `true` |
| `memoryDisplayValue` вычисляется | `CalculatorViewModel.swift:45-48` | `formatter.format(memoryValue)` → `"10"` (String?) |
| `memoryTooltip` собирается | `CalculatorView.swift:63` | `NSLocalizedString("memory.tooltip", ...) + viewModel.memoryDisplayValue!` |
| Тултип применяется | `CalculatorButton.swift:235` | `.helpIfPresent(spec.memoryTooltip)` |

**Ключевая строка — CalculatorView.swift:63:**
```swift
memoryTooltip: viewModel.memoryDisplayValue != nil
    ? NSLocalizedString("memory.tooltip", comment: "") + viewModel.memoryDisplayValue!
    : nil
```

---

## 2. Корневая причина (два дефекта в одном)

### Дефект А: `NSLocalizedString` возвращает ключ вместо значения

**Файл:** `Sources/Views/CalculatorView.swift:63`

`NSLocalizedString("memory.tooltip", comment: "")` возвращает строку `"memory.tooltip"` (сам ключ), а не локализованное значение `"Память: "` или `"Memory: "`.

**Почему:** В Swift Package Manager executable-таргете `.strings`-файлы упаковываются в `Bundle.module`. Метод `NSLocalizedString` без явного параметра `bundle:` ищет ключ в `Bundle.main`. Поскольку в `Bundle.main` нет `Localizable.strings`, метод возвращает ключ как fallback.

**Доказательство:**
- `Package.swift:44-46` — ресурсы определены: `.process("Localization")`
- `Package.swift:28-47` — таргет `CalculatorApp` — `executableTarget`, НЕ `target`
- `.strings`-файлы: `Sources/Localization/en.lproj/Localizable.strings:34` содержит `"memory.tooltip" = "Memory: ";`
- Конкатенация `"memory.tooltip"` + `"10"` = `"memory.tooltip10"` — именно то, что видит пользователь

**Верификация:** ключ `"memory.tooltip"` определён в обоих `.strings`-файлах:
- `Sources/Localization/en.lproj/Localizable.strings:34` — `"memory.tooltip" = "Memory: ";`
- `Sources/Localization/ru.lproj/Localizable.strings:34` — `"memory.tooltip" = "Память: ";`

### Дефект Б: Тултип появляется с задержкой ~5 секунд

**Причина:** Стандартный `.help()` модификатор macOS использует `NSToolTip` — системный механизм тултипов с фиксированной задержкой (~5 сек). Это поведение ОС, не баг кода. SwiftUI `.help()` не даёт контроль над задержкой.

---

## 3. Решение

### Исправление Дефекта А: добавить `Bundle.module` в `NSLocalizedString`

**Файл:** `Sources/Views/CalculatorView.swift`
**Строка:** 63

**Текущий код:**
```swift
ButtonSpec(label: .mR, type: .function, isEnabled: viewModel.hasMemory,
    hasMemoryIndicator: viewModel.hasMemory,
    memoryTooltip: viewModel.memoryDisplayValue != nil
        ? NSLocalizedString("memory.tooltip", comment: "") + viewModel.memoryDisplayValue!
        : nil),
```

**Новый код:**
```swift
ButtonSpec(label: .mR, type: .function, isEnabled: viewModel.hasMemory,
    hasMemoryIndicator: viewModel.hasMemory,
    memoryTooltip: viewModel.memoryDisplayValue != nil
        ? NSLocalizedString("memory.tooltip", bundle: .module, comment: "") + viewModel.memoryDisplayValue!
        : nil),
```

**Верификация:**
- `Bundle.module` — автоматически генерируемый SPM-свойство для таргета, имеющего `resources` (Package.swift:44-46) ✓
- `NSLocalizedString(_:bundle:comment:)` — стандартный метод Foundation, принимает `Bundle` ✓
- Сигнатура совпадает: `NSLocalizedString(String, bundle: Bundle, comment: String) -> String` ✓
- Значение из `en.lproj/Localizable.strings:34`: `"Memory: "` ✓
- Значение из `ru.lproj/Localizable.strings:34`: `"Память: "` ✓
- Итоговый тултип для MR с памятью 10: `"Память: 10"` (ru) / `"Memory: 10"` (en) ✓

### Исправление Дефекта Б: заменить `.help()` на `.popover()` для мгновенного отображения

**Причина:** `.help()` на macOS использует `NSToolTip` с задержкой ~5 сек, которую нельзя настроить. Единственный способ показывать подсказку мгновенно — использовать `.popover()`.

**Файл:** `Sources/Views/CalculatorButton.swift`
**Метод:** `helpIfPresent(_:)` (строки 251-261)

**Текущий код:**
```swift
extension View {
    /// Применяет .help() только когда подсказка не nil и не пуста
    @ViewBuilder
    func helpIfPresent(_ tip: String?) -> some View {
        if let tip, !tip.isEmpty {
            self.help(tip)
        } else {
            self
        }
    }
}
```

**Новый код:**
```swift
extension View {
    /// Показывает popover с текстом подсказки при наведении, если подсказка не nil и не пуста
    @ViewBuilder
    func helpIfPresent(_ tip: String?) -> some View {
        if let tip, !tip.isEmpty {
            self.popover(isPresented: Binding(
                get: { false },
                set: { _ in }
            )) {
                Text(tip)
                    .font(.system(size: 12))
                    .padding(6)
            }
        } else {
            self
        }
    }
}
```

**Проблема:** Статический `isPresented: Binding(get: { false }, set: { _ in })` не будет работать — popover никогда не покажется.

**Правильное решение:** Использовать `onHover` + `@State` для отслеживания состояния наведения. Поскольку `helpIfPresent` — это extension на `View`, а не отдельный View-компонент, нужен другой подход.

**Альтернатива:** Не модифицировать `helpIfPresent`, а заменить вызов в `CalculatorButton.body` на `onHover` + `popover`.

## 4. Детальный план изменений

### Изменение 1: `NSLocalizedString` с `Bundle.module`

**Файл:** `Sources/Views/CalculatorView.swift`
**Строка:** 63
**Действие:** Добавить `bundle: .module` в вызов `NSLocalizedString`

**До:**
```swift
memoryTooltip: viewModel.memoryDisplayValue != nil ? NSLocalizedString("memory.tooltip", comment: "") + viewModel.memoryDisplayValue! : nil),
```

**После:**
```swift
memoryTooltip: viewModel.memoryDisplayValue != nil ? NSLocalizedString("memory.tooltip", bundle: .module, comment: "") + viewModel.memoryDisplayValue! : nil),
```

**Единственное изменение в файле:** добавлен аргумент `bundle: .module`.

### Изменение 2: замена `.helpIfPresent()` на `onHover` + `.popover()` в CalculatorButton

**Файл:** `Sources/Views/CalculatorButton.swift`

**Шаг 2a:** Добавить `@State` переменную для отслеживания наведения.

**Строка:** 126 (после `@State private var isPressed = false`)

**Вставить:**
```swift
@State private var isHoveringTooltip = false
```

**Шаг 2b:** Заменить `.helpIfPresent(spec.memoryTooltip)` (строка 235) на `.onHover` + `.popover`.

**До (строка 235):**
```swift
.helpIfPresent(spec.memoryTooltip)
```

**После:**
```swift
.onHover { hovering in
    if spec.memoryTooltip != nil {
        isHoveringTooltip = hovering
    }
}
.popover(isPresented: $isHoveringTooltip) {
    if let tip = spec.memoryTooltip {
        Text(tip)
            .font(.system(size: 12))
            .padding(6)
    }
}
```

**Верификация:**
- `.onHover` — стандартный SwiftUI модификатор, доступен с macOS 13+ ✓
- `@State private var isHoveringTooltip: Bool` — реактивное состояние ✓
- `.popover(isPresented:)` — стандартный SwiftUI модификатор ✓
- `spec.memoryTooltip: String?` — свойство `ButtonSpec`, строка 112 ✓
- `Text(tip)` — простой текст в popover ✓
- Popover показывается мгновенно при наведении (нет задержки ~5 сек) ✓
- Popover исчезает при уходе курсора ✓

**Шаг 2c:** Удалить extension `helpIfPresent` (строки 249-261), если он больше не используется нигде в проекте.

**Проверка:** `helpIfPresent` вызывается ТОЛЬКО в CalculatorButton.swift:235. После замены на `onHover` + `.popover()` extension становится мёртвым кодом.

**Действие:** Удалить строки 249-261 (весь блок `// MARK: - Условные модификаторы` + `extension View { ... }`).
