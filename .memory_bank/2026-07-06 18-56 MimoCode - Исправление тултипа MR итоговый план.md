## 3. Выбранное решение (синтез лучших подходов)

### 3.1. Дефект A: сохранить локализацию + убрать force unwrap

**Решение OrnithQ8 лучше** по устранению force unwrap, **но MimoCode лучше** по сохранению локализации.

**Комбинированное решение:** добавить `bundle: .module` в `NSLocalizedString` И убрать force unwrap:

```swift
memoryTooltip: viewModel.memoryDisplayValue != nil
    ? NSLocalizedString("memory.tooltip", bundle: .module, comment: "") + viewModel.memoryDisplayValue!
    : nil
```

**Но** — `memoryDisplayValue` уже гарантированно не-nil в этой ветке ( ternary проверяет `!= nil` ), поэтому force unwrap безопасен. Однако, следуя правилам проекта §7.2 (запрет force unwrap без необходимости), используем `guard let`:

```swift
memoryTooltip: {
    guard let value = viewModel.memoryDisplayValue else { return nil as String? }
    return NSLocalizedString("memory.tooltip", bundle: .module, comment: "") + value
}()
```

Или, ещё проще и чище — через `map`:

```swift
memoryTooltip: viewModel.memoryDisplayValue.map {
    NSLocalizedString("memory.tooltip", bundle: .module, comment: "") + $0
}
```

**Выбран вариант с `map`** — он устраняет force unwrap, сохраняет локализацию, и является идиоматичным Swift.

### 3.2. Дефект B: hover-активный тултип через `onHover` + `.popover`

**`.popover()` лучше `.overlay()`**, потому что:
- Popover автоматически позиционируется и не конфликтует с другими overlay
- Popover исчезает при потере фокуса
- Popover визуально соответствует стандартным подсказкам macOS

**`.onHover` + `@State`** необходимы для привязки к hover-состоянию (в отличие от всегда-видимого `.overlay` из плана OrnithQ8).

### Изменение 3: Заменить `.helpIfPresent()` на `.onHover` + `.popover()`

**Файл:** `Sources/Views/CalculatorButton.swift`
**Строка:** 235
**Тип:** Замена существующего кода

**Текущий код (строка 235):**
```swift
        .helpIfPresent(spec.memoryTooltip)
```

**Новый код (строки 235–244):**
```swift
        .onHover { hovering in
            if spec.memoryTooltip != nil {
                isHoveringTooltip = hovering
            }
        }
        .popover(isPresented: $isHoveringTooltip) {
            if let tip = spec.memoryTooltip {
                Text(tip)
                    .font(.system(size: 12))
                    .padding(6)
            }
        }
```

**Что изменилось:**
- `.helpIfPresent(spec.memoryTooltip)` — удалён вызов extension-метода
- Добавлен `.onHover` — при наведении курсора на кнопку устанавливает `isHoveringTooltip = true`
- Добавлен `.popover(isPresented:)` — показывает всплывающее окно с текстом тултипа
- Guard `if spec.memoryTooltip != nil` — тултип активируется только когда `memoryTooltip` не `nil` (т.е. только для MR с памятью)

**Верификация:**
- `.onHover` — SwiftUI модификатор, доступен с macOS 13.0+ (проект: macOS 14.0+, совместимо)
- `.popover(isPresented:)` — SwiftUI модификатор, доступен с macOS 10.15+ (совместимо)
- `$isHoveringTooltip` — `Binding<Bool>`, созданный из `@State private var isHoveringTooltip`
- `spec.memoryTooltip` — тип `String?` (`Sources/Views/CalculatorButton.swift:112`)
- `Text(tip)` — стандартный SwiftUI компонент
- `.font(.system(size: 12))` — стандартный модификатор
- `.padding(6)` — стандартный модификатор
- Popover показывается **мгновенно** при наведении (нет системной задержки ~5 сек)
- Popover исчезает при уходе курсора с кнопки

**Почему `.popover()` лучше `.overlay()`:**
- Overlay (план OrnithQ8) показывает текст **всегда** — это не тултип, а permanent надпись
- Popover привязан к `isHoveringTooltip` — показывается только при наведении
- Popover автоматически позиционируется системой (не нужно рассчитывать `padding(.bottom, diameter + 4)`)
- Popover исчезает при потере фокуса — стандартное поведение

**Почему `onHover` + `@State` лучше alternatives:**
- Статический `Binding(get: { false }, set: { _ in })` (план MimoCode v1) — popover никогда не покажется
- `onHover` + `@State` — стандартный паттерн в SwiftUI для hover-привязанных элементов
