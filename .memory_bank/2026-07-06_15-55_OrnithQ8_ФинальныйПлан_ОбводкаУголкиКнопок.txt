## 0. ИНСТРУКЦИЯ ДЛЯ ИСПОЛНИТЕЛЯ

Этот план описывает пошаговые изменения для визуального улучшения кнопок калькулятора:
1. Увеличить закругление уголков у оранжевых кнопок (арифметические операторы) с 12 до 16
2. Добавить тонкую серую обводку вокруг белых кнопок (цифры и функциональные)

Все утверждения верифицированы путём чтения фактического исходного кода.
Каждый шаг содержит: точный путь файла, точные номера строк, полный контекст «было» и «стало».

**ВАЖНО:** Не пропускайте ни одного шага. Не меняйте порядок. Не добавляйте свой код.

## 3. АРХИТЕКТУРНОЕ РЕШЕНИЕ

### 3.1 Суть решения

Добавить в `CalculatorButton` три вычисляемых свойства:
1. `buttonCornerRadius: CGFloat` — зависит от типа кнопки (operator = 16, digit/function = 12)
2. `hasBorder: Bool` — true для белых кнопок (digit, function), false для оранжевых (operator)
3. `borderColor: Color` — цвет обводки (системный серый, адаптируется к теме)

Использовать `.overlay { }` с `RoundedRectangle(stroke: ...)` для обводки белых кнопок.

### 3.2 Верификация КАЖДОГО используемого API

**Утверждение 1: `RoundedRectangle(cornerRadius:)` — стандартный SwiftUI shape.**
- Подтверждено: CalculatorButton.swift:173 уже использует `RoundedRectangle(cornerRadius: 12)` в текущем коде.
- SwiftUI предоставляет `RoundedRectangle` с настраиваемым `cornerRadius: CGFloat`.

**Утверждение 2: `.overlay { }` — стандартный SwiftUI модификатор (closure-based overlay).**
- Подтверждено: `.overlay(content:)` — модификатор SwiftUI, принимающий замыкание, возвращающее View.
- Доступен начиная с macOS 11. Проект targets `.macOS(.v14)` (Package.swift:8) — модификатор доступен.
- Внутри замыкания можно использовать `if`/`else`, `for` и другие конструкции — это обрабатывается фреймворком `@ViewBuilder`.
- Когда условие `if` ложно и ветка `else` отсутствует, `@ViewBuilder` автоматически подставляет `EmptyView()` — ничего не отображается.

**Утверждение 3: `.stroke(color:lineWidth:)` — стандартный модификатор для Shape.**
- Подтверждено: `RoundedRectangle` conforms to `Shape`. Модификатор `.stroke(color:lineWidth:)` применяется к любому `Shape` и возвращает `Stroke<S>`, который conforms to `View`.
- Параметры: `color: Color` (SwiftUI Color), `lineWidth: CGFloat` (по умолчанию 1.0).

**Утверждение 4: `Color.secondary` — стандартный SwiftUI цвет, адаптирующийся к теме.**
- Подтверждено: `Color.secondary` — статическое свойство SwiftUI `Color`, возвращающее цвет вторичного текста/элементов.
- Адаптируется к светлой/тёмной теме через `@Environment(\.colorScheme)`.
- Доступен начиная с iOS 13 / macOS 10.15. Проект targets macOS 14 — цвет доступен.
- Преимущество перед `NSColor.systemGray`: не требует `import AppKit` в файле CalculatorButton.swift (который содержит только `import SwiftUI`).

**Утверждение 5: `spec.type` доступен в body CalculatorButton.**
- Подтверждено: CalculatorButton.swift:128-134 — свойство `backgroundColor` уже использует `spec.type` в `switch`.
- `spec: ButtonSpec` — свойство типа `ButtonSpec` (строка 116), содержащее `type: CalcButtonType`.
- Вычисляемые свойства, которые мы добавляем, находятся в той же структуре `CalculatorButton`, поэтому имеют полный доступ к `spec.type`.

**Утверждение 6: `.overlay()` не влияет на размер (frame) кнопки.**
- Подтверждено: `.overlay(content:)` добавляет view поверх основного, не изменяя frame родительского view.
- `.frame(width: targetWidth, height: diameter)` (строка 164) остаётся без изменений.

**Утверждение 7: `Capsule()` для wide-кнопки "0" не требует обводку.**
- Подтверждено: CalculatorButton.swift:172 — wide-кнопка использует `AnyShape(Capsule())`.
- Обводка (stroke) вокруг Capsule выглядит некорректно визуально.
- **Решение:** Обводку применять только для не-wide кнопок (условие `!spec.isWide`).

**Утверждение 8: `switch spec.type` покрывает все случаи.**
- Подтверждено: CalcButtonType имеет ровно 3 случая: `.digit`, `.operator`, `.function` (CalculatorButton.swift:5-12).
- Вычисляемое свойство `buttonCornerRadius` будет использовать `switch` со всеми тремя случаями — это exhaustiveness check, Swift потребует покрытия всех случаев.

**Утверждение 9: `AnyShape` необходим в `.clipShape()` для ternary между Capsule и RoundedRectangle.**
- Подтверждено: CalculatorButton.swift:171-173 — текущий код использует `AnyShape` для приведения типов в тернарном операторе.
- `Capsule` и `RoundedRectangle(cornerRadius:)` — разные типы, conforming к `Shape`. Тернарный оператор требует одинаковый тип обеих ветвей.
- `AnyShape` стирает тип, делая обе ветви совместимыми. Это необходимо и для нового кода (где `RoundedRectangle` использует переменную `buttonCornerRadius`).

**Утверждение 10: `.background()` и `.overlay()` — разные модификаторы с разным поведением.**
- Подтверждено: `.background()` (строки 165-169) добавляет фон ВНУТРЬ frame. `.overlay()` добавляет view СВЕРХУ основного view.
- `.border()` (альтернатива, отклонённая) рисует рамку, центрированную на границе view — половина внутри, половина снаружи frame. `.overlay()` с `stroke` рисует рамку поверх, не изменяя layout.

**Что добавлено (пояснение для исполнителя):**

1. **`buttonCornerRadius: CGFloat`** — вычисляемое свойство, возвращающее радиус закругления в зависимости от типа кнопки:
   - `.operator` → 16 (больше текущего 12, визуально более округлые оранжевые кнопки)
   - `.digit`, `.function` → 12 (текущее значение, без изменений)
   - `switch` покрывает все 3 случая `CalcButtonType` (exhaustive)

2. **`hasBorder: Bool`** — вычисляемое свойство, определяющее, нужна ли обводка:
   - `.digit`, `.function` → true (белые/светло-серые кнопки нуждаются в обводке)
   - `.operator` → false (оранжевые кнопки не нуждаются в обводке)

3. **`borderColor: Color`** — вычисляемое свойство, возвращающее цвет обводки:
   - `Color.secondary` — стандартный SwiftUI-цвет, автоматически адаптируется к светлой/тёмной теме
   - НЕ используется `NSColor.systemGray`, потому что файл CalculatorButton.swift не импортирует AppKit (только `import SwiftUI` на строке 1)

**Верификация каждого элемента нового кода:**
- `private var buttonCornerRadius: CGFloat` — корректный синтаксис вычисляемого свойства Swift
- `switch spec.type` — `spec` доступен как свойство структуры (строка 116), `.type` имеет тип `CalcButtonType` (ButtonSpec:108)
- `case .operator:` — обратные кавычки не нужны в switch case, даже если enum case называется `operator` (ключевое слово). Swift разрешает это.
- `case .digit, .function:` — группировка случаев в одном case через запятую допустима в Swift switch
- `private var hasBorder: Bool` — корректный синтаксис, возвращает Bool
- `private var borderColor: Color` — корректный синтаксис, возвращает SwiftUI Color
- `Color.secondary` — статическое свойство SwiftUI.Color, доступно на macOS 14
- Разделитель `// MARK: - Визуальные свойства кнопок` — принятый в проекте стиль (аналогично `// MARK: Body`, `// MARK: Цвета`)

### ОПЕРАЦИЯ 2: Изменить `.clipShape()` и добавить `.overlay()` для обводки

**Файл:** `Sources/Views/CalculatorButton.swift`
**Расположение:** Строки 170-174 (блок `.clipShape(...)` внутри `label:` closure)

**Текущий код (строки 170-174):**
```swift
                .clipShape(
                    spec.isWide
                        ? AnyShape(Capsule())
                        : AnyShape(RoundedRectangle(cornerRadius: 12))
                )
```

**Новый код (замена строк 170-174):**
```swift
                .clipShape(
                    spec.isWide
                        ? AnyShape(Capsule())
                        : AnyShape(RoundedRectangle(cornerRadius: buttonCornerRadius))
                )
                .overlay {
                    if hasBorder && !spec.isWide {
                        RoundedRectangle(cornerRadius: buttonCornerRadius)
                            .stroke(borderColor, lineWidth: 1.0)
                    }
                }
```

**Что изменено (пояснение для исполнителя):**

1. **Строка 173:** `cornerRadius: 12` → `cornerRadius: buttonCornerRadius`
   - Теперь радиус закругления вычисляется динамически: 16 для операторов, 12 для остальных
   - `buttonCornerRadius` — вычисляемое свойство, добавленное в Операции 1

2. **Строки 175-180 (новое):** добавлен `.overlay { }` после `.clipShape()`
   - `.overlay { }` — closure-based overlay модификатор (подтверждено в разделе 3.2, Утверждение 2)
   - Внутри замыкания `if hasBorder && !spec.isWide` — двойное условие:
     - `hasBorder` (true для `.digit` и `.function`, false для `.operator`) — обводка только для белых кнопок
     - `!spec.isWide` (false для кнопки "0") — обводка только для не-wide кнопок
   - Когда условие ложно (оранжевые кнопки или wide-кнопка "0"), `@ViewBuilder` подставляет `EmptyView()` — overlay не отображается
   - Когда условие истинно (белые не-wide кнопки), рендерится:
     - `RoundedRectangle(cornerRadius: buttonCornerRadius)` — форма с таким же радиусом, как у clipShape
     - `.stroke(borderColor, lineWidth: 1.0)` — обводка формы цветом `borderColor` толщиной 1.0pt
   - `lineWidth: 1.0` — явное указание толщины линии (CGFloat). Можно написать `1.0` или `1`, оба варианта корректны.

**Почему используется `.overlay { }` (closure), а не тернарный оператор с `Color.clear`:**
- Closure-based overlay чище и понятнее для исполнителя
- Не требует создания `Color.clear` как fallback-ветви
- `@ViewBuilder` автоматически обрабатывает отсутствие `else` в `if` внутри замыкания
- Меньше кода — проще прочитать и проверить

**Почему обводка применяется ПОСЛЕ `.clipShape()`:**
- `.clipShape()` определяет форму кнопки (закруглённый прямоугольник или капсула)
- `.overlay()` добавляет визуальный элемент СВЕРХУ уже обрезанной формы
- Обводка рисуется внутри frame кнопки (не выходит за границы), не влияя на layout

**Верификация каждого элемента нового кода:**
- `buttonCornerRadius` — вычисляемое свойство, добавленное в Операции 1 (тип CGFloat)
- `.overlay { }` — модификатор SwiftUI, доступен на macOS 14 (подтверждено: Утверждение 2)
- `hasBorder` — вычисляемое свойство, добавленное в Операции 1 (тип Bool)
- `spec.isWide` — свойство ButtonSpec (CalculatorButton.swift:109, тип Bool)
- `&&` — оператор логического И в Swift, объединяет два Bool
- `!spec.isWide` — оператор отрицания, инвертирует Bool
- `RoundedRectangle(cornerRadius: buttonCornerRadius)` — стандартный SwiftUI shape, cornerRadius принимает CGFloat
- `.stroke(borderColor, lineWidth: 1.0)` — модификатор Shape, borderColor тип Color, lineWidth тип CGFloat
- `borderColor` — вычисляемое свойство, добавленное в Операции 1 (тип Color)
