# План: Стилизация кнопок калькулятора

**Дата:** 2026-07-06 00:06  
**Агент:** MimoCode  
**Задача:** Увеличить закругление оранжевых кнопок, добавить обводку белым кнопкам

---

## Цель

Сделать кнопки калькулятора визуально разграниченнее:
1. Кнопки операторов (оранжевые) — более выраженные скруглённые углы.
2. Кнопки цифр/функций (белые) — тонкая серая рамка вокруг, с таким же скруглением.

---

## Текущее состояние

**Файл:** `Sources/Views/CalculatorButton.swift`

Сейчас все обычные кнопки используют один и тот же shape:
```swift
AnyShape(RoundedRectangle(cornerRadius: 12))
```
Кнопка "0" (широкая) использует `AnyShape(Capsule())`.

Цвета определены в `Sources/Theme/CalculatorColors.swift`:
- `buttonDigit` — серый фон цифр
- `buttonFunction` — белый/светлый фон функций
- `buttonOperator` — оранжевый фон операторов

---

## Изменения

### Файл: `Sources/Views/CalculatorButton.swift`

#### 1. Добавить свойство для cornerRadius в зависимости от типа кнопки

В структуре `CalculatorButton` добавить computed property:

```swift
private var cornerRadius: CGFloat {
    switch spec.type {
    case .operator:  return 16   // было 12, стало больше
    case .digit:     return 12   // без изменений
    case .function:  return 12   // без изменений
    }
}
```

#### 2. Заменить захардкоженный cornerRadius: 12 на cornerRadius

В current code (строка ~173):
```swift
// Было:
AnyShape(RoundedRectangle(cornerRadius: 12))

// Стало:
AnyShape(RoundedRectangle(cornerRadius: cornerRadius))
```

#### 3. Добавить обводку (stroke) для не-оранжевых кнопок

В current code (строки ~165-169) фон кнопки задаётся через `.background(...)`:

```swift
// Было:
.background(
    isPressed
        ? CalculatorColors.pressedColor(for: backgroundColor)
        : backgroundColor
)
```

Заменить на:

```swift
.background(
    isPressed
        ? CalculatorColors.pressedColor(for: backgroundColor)
        : backgroundColor
)
.overlay(
    spec.type != .operator
        ? AnyShape(RoundedRectangle(cornerRadius: cornerRadius))
            .stroke(Color.gray.opacity(0.3), lineWidth: 1)
        : AnyShape(RoundedRectangle(cornerRadius: cornerRadius))
            .stroke(Color.clear, lineWidth: 0)
)
```

Альтернативный вариант (чище) — вынести обводку в отдельный computed property:

```swift
private var strokeOverlay: some View {
    Group {
        if spec.type != .operator {
            AnyShape(RoundedRectangle(cornerRadius: cornerRadius))
                .stroke(Color.gray.opacity(0.3), lineWidth: 1)
        }
    }
}
```

И применить:
```swift
.background(...)
.overlay(strokeOverlay)
```

#### 4. Учёт широкой кнопки "0"

Кнопка "0" использует `Capsule()` — для неё обводка не требуется (у неё уже есть визуальная форма). Проверить условие: `spec.isWide` должен исключаться из обводки.

Корректное условие обводки:
```swift
if spec.type != .operator && !spec.isWide {
    // обводка
}
```
