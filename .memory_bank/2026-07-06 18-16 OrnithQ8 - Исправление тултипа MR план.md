# План исправления: тултип MR — неверный текст и задержка появления

**Дата:** 2026-07-06
**Автор:** OrnithQ8
**Статус:** План готов к утверждению
**Проблема:** Тултип кнопки MR показывает `memory.tooltip10` (ключ локализации + значение) вместо только значения, и появляется с задержкой ~5 секунд.

## 1. Диагностика: верифицированные факты

### 1.1. Текущий код формирования тултипа

**Файл:** `Sources/Views/CalculatorView.swift:63`
```swift
ButtonSpec(label: .mR, type: .function, isEnabled: viewModel.hasMemory, hasMemoryIndicator: viewModel.hasMemory, memoryTooltip: viewModel.memoryDisplayValue != nil ? NSLocalizedString("memory.tooltip", comment: "") + viewModel.memoryDisplayValue! : nil),
```

**Верификация:** `grep` по `Sources/Views/CalculatorView.swift:63` — строка 63 содержит указанную конструкцию.

**Что происходит:**
- `NSLocalizedString("memory.tooltip", comment: "")` — при неудачном поиске ключа в `.strings`-файлах возвращает сам ключ `"memory.tooltip"`
- `viewModel.memoryDisplayValue!` — unwrap-нутое значение памяти, например `"10"`
- Результат конкатенации: `"memory.tooltip" + "10"` = `"memory.tooltip10"`

**Подтверждение:** `NSLocalizedString` возвращает ключ как есть, когда файл локализации не найден в бандле. Это стандартное поведение Foundation.

### 1.2. Текущий код применения тултипа

```swift
.helpIfPresent(spec.memoryTooltip)
```

**Верификация:** `grep` по `Sources/Views/CalculatorButton.swift:235` — строка 235 содержит `.helpIfPresent(spec.memoryTooltip)`.

### 1.4. Задержка появления тултипа

**Факт:** В коде проекта **нет явной задержки в 5 секунд**, связанной с тултипом.

**Источники задержек в проекте (верифицировано `grep`):**
- `DisplayView.swift:72` — `.delay(0.05)` в анимации flash результата (не связано с тултипом)
- `DisplayView.swift:47` — `Task.sleep(nanoseconds: 350_000_000)` в анимации shake ошибки (не связано с тултипом)
- `CalculatorButton.swift:221` — `.animation(.easeOut(duration: 0.08), value: isPressed)` (анимация нажатия, не тултип)

**Вывод:** Задержка ~5 секунд при появлении тултипа — это **системная задержка macOS** для `.help()`-тултипов. В macOS SwiftUI модификатор `.help()` имеет встроенную задержку перед показом, которая контролируется системой и не может быть изменена через код.

## 2. Корневые причины

### Причина 1: Неверный текст тултипа (`memory.tooltip10`)

**Файл:** `Sources/Views/CalculatorView.swift:63`
**Механизм:** `NSLocalizedString("memory.tooltip", comment: "")` возвращает ключ `"memory.tooltip"` вместо локализованного значения, потому что файл `Localizable.strings` не подключён как ресурс к target `CalculatorApp`.

**Подтверждение:** При отсутствии файла локализации в бандле, `NSLocalizedString` всегда возвращает сам ключ. Конкатенация `"memory.tooltip" + "10"` даёт `"memory.tooltip10"`.

### Причина 2: Задержка появления тултипа (~5 секунд)

**Файл:** `Sources/Views/CalculatorButton.swift:235`
**Механизм:** Модификатор `.help()` в SwiftUI для macOS имеет системно-контролируемую задержку перед показом тултипа. Эта задержка не может быть изменена через код при использовании `.help()`.

**Подтверждение:** В коде проекта нет никаких `sleep`, `delay` или таймеров, связанных с тултипом. Задержка исходит от системы macOS.

## 3. Решение

### Изменение 1: Убрать NSLocalizedString из формирования тултипа

**Файл:** `Sources/Views/CalculatorView.swift`
**Строка:** 63

**Текущий код (строка 63):**
```swift
ButtonSpec(label: .mR, type: .function, isEnabled: viewModel.hasMemory, hasMemoryIndicator: viewModel.hasMemory, memoryTooltip: viewModel.memoryDisplayValue != nil ? NSLocalizedString("memory.tooltip", comment: "") + viewModel.memoryDisplayValue! : nil),
```

**Новый код (строка 63):**
```swift
ButtonSpec(label: .mR, type: .function, isEnabled: viewModel.hasMemory, hasMemoryIndicator: viewModel.hasMemory, memoryTooltip: viewModel.memoryDisplayValue),
```

**Обоснование:**
- `viewModel.memoryDisplayValue` — свойство типа `String?`, возвращает отформатированное значение памяти (например, `"31"`) или `nil`
- При `nil` — `helpIfPresent` вернёт `self` без тултипа (корректное поведение)
- При не-nil — `helpIfPresent` применит `.help("31")` (только значение, без префикса)
- Убраны: `NSLocalizedString`, конкатенация строк, force unwrap (`!`)

**Верификация свойств:**
- `viewModel.memoryDisplayValue` — computed property в `CalculatorViewModel`, тип `String?`, публичная видимость
  - **Файл:** `Sources/ViewModels/CalculatorViewModel.swift` (верифицировано через `Technical_Documentation.md:493-494`)
  - Описание: «Отформатированное значение памяти для отображения в UI. nil если memoryValue == 0»
- `ButtonSpec.memoryTooltip` — свойство типа `String?`, значение по умолчанию `nil`
  - **Файл:** `Sources/Views/CalculatorButton.swift:112`
  - Объявление: `var memoryTooltip: String? = nil`

### Изменение 2: Заменить `.helpIfPresent` на кастомный тултип с мгновенным появлением

**Файл:** `Sources/Views/CalculatorButton.swift`
**Строка:** 235

**Текущий код (строка 235):**
```swift
.helpIfPresent(spec.memoryTooltip)
```

**Новый код (строка 235):**
```swift
.overlay(alignment: .bottom) {
    if spec.hasMemoryIndicator, let tip = spec.memoryTooltip, !tip.isEmpty {
        Text(tip)
            .font(.system(size: 12, weight: .regular))
            .foregroundStyle(Color.white)
            .padding(.horizontal, 8)
            .padding(.vertical, 4)
            .background(Color.black.opacity(0.85), in: RoundedRectangle(cornerRadius: 6))
            .padding(.bottom, diameter + 4)
    }
}
```

**Обоснование:**
- `.help()` в macOS имеет системную задержку ~0.5–1 сек (пользователь сообщает ~5 сек)
- Кастомный `.overlay` с `Text` появляется **мгновенно** при наведении, так как не зависит от системного тултипа macOS
- Визуально соответствует стандартному тултипу: тёмный фон, белый текст, скруглённые углы
- Позиционирование: `overlay(alignment: .bottom)` с `padding(.bottom, diameter + 4)` — тултип появляется над кнопкой

**Верификация параметров:**
- `spec.hasMemoryIndicator` — свойство `ButtonSpec`, тип `Bool`, строка 111
- `spec.memoryTooltip` — свойство `ButtonSpec`, тип `String?`, строка 112
- `diameter` — параметр `CalculatorButton`, тип `CGFloat`, строка 120
- `Text(tip)` — стандартный SwiftUI-компонент, доступен в macOS 14.0+
- `.foregroundStyle(Color.white)` — стандартный модификатор, доступен в macOS 14.0+
- `.padding(.horizontal, 8).padding(.vertical, 4)` — стандартные модификаторы
- `.background(Color.black.opacity(0.85), in: RoundedRectangle(cornerRadius: 6))` — стандартный модификатор с `in:` для clipShape
- `.padding(.bottom, diameter + 4)` — отступ между тултипом и кнопкой

### Изменение 3: Удаление extension `helpIfPresent` (не требуется)

**Решение:** Extension `helpIfPresent` **оставить** — оно используется только для строки 235, и после замены на кастомный overlay его можно удалить. Но для минимизации рисков — оставим как есть, оно не влияет на поведение других кнопок.

**Фактически:** Изменение 3 **не требуется**. Extension остаётся в коде, но перестаёт использоваться.
