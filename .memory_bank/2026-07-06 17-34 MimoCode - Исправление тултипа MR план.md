# План исправления: тултип не появляется на кнопке MR

**Дата:** 2026-07-06
**Автор:** MimoCode
**Статус:** План готов к утверждению
**Проблема:** После выполнения плана OrnithQ8 всплывающая подсказка (tooltip) при наведении курсора на кнопку MR не отображается, хотя зелёный индикатор работает корректно.

---

## 1. Диагностика: что работает, а что нет

| Компонент | Файл:строка | Статус |
|---|---|---|
| `memoryDisplayValue: String?` | `CalculatorViewModel.swift:44-48` | Работает |
| `hasMemoryIndicator: Bool`, `memoryTooltip: String?` в `ButtonSpec` | `CalculatorButton.swift:111-112` | Работает |
| Передача данных в ButtonSpec для `.mR` | `CalculatorView.swift:63` | Работает |
| Зелёный кружочек через `.overlay()` | `CalculatorButton.swift:210-218` | Работает |
| Локализация `memory.tooltip` | `en.lproj:34`, `ru.lproj:34` | Работает |
| `.help(spec.memoryTooltip ?? "")` | `CalculatorButton.swift:235` | **Не работает** |

---

## 2. Корневая причина

**Файл:** `Sources/Views/CalculatorButton.swift:235`
```swift
.help(spec.memoryTooltip ?? "")
```

Оператор `?? ""` заменяет `nil` на пустую строку. На macOS SwiftUI `.help("")` **не подавляет** тултип — он создаёт пустой невидимый tooltip-элемент. Это происходит на **всех 18 кнопках** (17 с `nil` + 1 MR). Система тултипов macOS получает 18 конкурирующих пустых подсказок, и реальный тултип MR блокируется.

**Цепочка данных для MR корректна:**
1. `memoryValue = 31` → `hasMemory = true` → `memoryDisplayValue = "31"`
2. `CalculatorView:63` → `memoryTooltip = "Память: 31"`
3. `CalculatorButton:235` → `.help("Память: 31")`

Проблема не в данных, а в том, что `.help()` вызывается для **всех** кнопок, включая 17 кнопок с пустым тултипом.

---

## 3. Решение

Заменить `.help(spec.memoryTooltip ?? "")` на **условный** вызов `.help()`, который **вообще не применяется** к кнопкам без тултипа.

В SwiftUI нельзя условно применить модификатор напрямую в цепочке. Используется `View` extension с `@ViewBuilder` и `if let` — это стандартный паттерн, а не кастомный хак.

---

## 4. Изменения

### Изменение 1: добавить View extension `helpIfPresent`

**Файл:** `Sources/Views/CalculatorButton.swift`
**Где:** После строки 247 (конец файла, после `extension AnyShape: @unchecked Sendable {}`)

**Код для вставки:**
```swift

// MARK: - Условные модификаторы

extension View {
    /// Применяет .help() только когда подсказка не nil и не пуста
    @ViewBuilder
    func helpIfPresent(_ tip: String?) -> some View {
        if let tip, !tip.isEmpty {
            self.help(tip)
        } else {
            self
        }
    }
}
```

**Верификация:**
- `View` — протокол SwiftUI, импорт на строке 1 файла ✓
- `@ViewBuilder` — стандартный attribute SwiftUI ✓
- `self.help(tip)` — стандартный модификатор macOS 13+ ✓
- Метод `helpIfPresent` — уникальное имя, не конфликтует ✓

**Поведение:**
- `helpIfPresent(nil)` → `self` (без тултипа)
- `helpIfPresent("")` → `self` (без тултипа)
- `helpIfPresent("Память: 31")` → `self.help("Память: 31")` (с тултипом)

### Изменение 2: замена строки в CalculatorButton

**Файл:** `Sources/Views/CalculatorButton.swift`
**Строка 235**

**Текущий код:**
```swift
        .help(spec.memoryTooltip ?? "")
```

**Новый код:**
```swift
        .helpIfPresent(spec.memoryTooltip)
```

**Верификация:**
- `spec.memoryTooltip` — свойство `ButtonSpec`, тип `String?` (строка 112) ✓
- `helpIfPresent(_:)` — метод из Изменения 1 ✓
- Убран `?? ""` — пустая строка больше не передаётся ✓
