**Дефект Б (задержка):** Замена `.helpIfPresent()` на безусловный `.overlay()`. Причина: overlay рендерится всегда (не зависит от hover-состояния), текст виден сразу при появлении кнопки с памятью.

## Детальный план изменений

### Изменение 1: Упростить формирование memoryTooltip

**Файл:** `Sources/Views/CalculatorView.swift`
**Строка:** 63
**Причина:** Текущий код конкатенирует `NSLocalizedString("memory.tooltip", comment: "")` (возвращает ключ "memory.tooltip" вместо локализованного значения) с `viewModel.memoryDisplayValue!` (force unwrap). Результат: "memory.tooltip10" вместо "10".

**Текущий код (строка 63):**
```swift
                ButtonSpec(label: .mR,             type: .function, isEnabled: viewModel.hasMemory, hasMemoryIndicator: viewModel.hasMemory, memoryTooltip: viewModel.memoryDisplayValue != nil ? NSLocalizedString("memory.tooltip", comment: "") + viewModel.memoryDisplayValue! : nil),
```

**Новый код (строка 63):**
```swift
                ButtonSpec(label: .mR,             type: .function, isEnabled: viewModel.hasMemory, hasMemoryIndicator: viewModel.hasMemory, memoryTooltip: viewModel.memoryDisplayValue),
```

**Что изменилось:**
- Удалён `NSLocalizedString("memory.tooltip", comment: "")` — источник бага (возвращал ключ вместо значения)
- Удалена конкатенация `+ viewModel.memoryDisplayValue!` — force unwrap заменён на безопасную передачу `String?`
- Удалён тернарный оператор `!= nil ? ... : nil` — `memoryDisplayValue` уже возвращает `String?` (nil если memoryValue == 0)
- `ButtonSpec.memoryTooltip` принимает `String?` — тип совпадает

**Верификация:**
- `viewModel.memoryDisplayValue` → `String?` (CalculatorViewModel.swift:45-48) ✅
- `ButtonSpec.memoryTooltip: String? = nil` (CalculatorButton.swift:112) ✅
- При nil — `helpIfPresent` вернёт `self` без тултипа ✅
- При не-nil (например, "10") — `helpIfPresent` применит `.help("10")` ✅

### Изменение 2: Заменить `.helpIfPresent()` на кастомный `.overlay()`

**Файл:** `Sources/Views/CalculatorButton.swift`
**Строка:** 235
**Причина:** `.help()` использует системный `NSToolTip` с задержкой ~5 сек. Кастомный `.overlay()` рендерится мгновенно — текст появляется сразу при наведении.

**Текущий код (строка 235):**
```swift
        .helpIfPresent(spec.memoryTooltip)
```

**Новый код (строки 235-248):**
```swift
        .overlay {
            if let tip = spec.memoryTooltip, !tip.isEmpty {
                Text(tip)
                    .font(.system(size: 12, weight: .regular))
                    .foregroundStyle(Color.white)
                    .padding(.horizontal, 8)
                    .padding(.vertical, 4)
                    .background(Color.black.opacity(0.85), in: RoundedRectangle(cornerRadius: 6))
                    .padding(.bottom, diameter + 4)
            }
        }
```

**Что изменилось:**
- `.helpIfPresent(spec.memoryTooltip)` → блок `.overlay { ... }`
- Текст тултипа появляется мгновенно (без задержки ~5 сек)
- Условие `if let tip = spec.memoryTooltip, !tip.isEmpty` — рендерит overlay только при наличии непустой строки
- Визуальный стиль: тёмный фон (85% непрозрачный чёрный), белый текст, скруглённые углы 6pt — стандартный вид тултипа macOS
- Позиционирование: `.padding(.bottom, diameter + 4)` — отступ снизу = диаметр кнопки + 4pt

**Верификация:**
- `.overlay` — стандартный SwiftUI модификатор, доступен в macOS 14.0+ ✅
- `spec.memoryTooltip` — `String?` (CalculatorButton.swift:112) ✅
- `diameter` — `CGFloat` параметр CalculatorButton (CalculatorButton.swift:120) ✅
- `Text(tip)` — стандартный SwiftUI компонент ✅
- `.font(.system(size: 12, weight: .regular))` — стандартный модификатор ✅
- `.foregroundStyle(Color.white)` — доступен в macOS 14.0+ ✅
- `.background(Color.black.opacity(0.85), in: RoundedRectangle(cornerRadius: 6))` — стандартный модификатор ✅
- Два `.overlay()` в одном View не конфликтуют (первый — `.bottomTrailing` для индикатора, второй — для тултипа) ✅

### Изменение 3: Удалить мёртвый код extension `helpIfPresent`

**Файл:** `Sources/Views/CalculatorButton.swift`
**Строки:** 249-261
**Причина:** После замены `.helpIfPresent()` на `.overlay()` extension `helpIfPresent` перестаёт использоваться. Мёртвый код подлежит удалению согласно AGENTS.md §11.2.

**Текущий код (строки 249-261):**
```swift

// MARK: - Условные модификаторы

extension View {
    /// Применяет .help() только когда подсказка не nil и не пуста
    @ViewBuilder
    func helpIfPresent(_ tip: String?) -> some View {
        if let tip, !tip.isEmpty {
            self.help(tip)
        } else {
            self
        }
    }
}
```

**Действие:** Удалить строки 249-261 целиком (включая пустую строку 249 и MARK-комментарий 249).

**Верификация:** `helpIfPresent` вызывается только в CalculatorButton.swift:235 (подтверждено чтением файла). После замены на `.overlay()` других вызовов нет.
